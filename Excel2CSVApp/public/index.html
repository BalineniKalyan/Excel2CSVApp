API Documentation

Convert Excel to CSV

POST /api/convert

Request: Send Excel file as binary (Content-Type: application/octet-stream)

Response: CSV file as binary (application/octet-stream)


Example using cURL:

curl -X POST -H "Content-Type: application/octet-stream" --data-binary @file.xlsx http://localhost:3000/api/convert -o output.csv
